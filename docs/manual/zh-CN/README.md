# kiku 用户手册

kiku 是一个自托管的 DLsite 音声作品媒体服务器：在线播放 + 媒体库管理。

> English: [User Manual](../en/README.md)

## 目录

- **[安装部署](installation.md)** — Docker Compose 部署、源码运行、初始化向导、从 kikoeru 迁移
- **[管理后台](library.md)** — 根文件夹、扫描、任务中心、DLsite 元数据、响度分析、服务器设置、用户管理
- **[浏览与个人数据](browsing.md)** — 搜索与筛选、排序、收藏、评分与评价、已读标记、收听历史
- **[播放器](playback.md)** — 播放控制、播放队列、视频播放、歌词、睡眠定时器、音量均衡
- **[个人设置](settings.md)** — 外观、播放偏好、R-18 封面模糊、设置备份、账户
